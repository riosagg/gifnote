# テストガイド

[README](../README.md) / [開発ガイド](DEVELOPMENT.md)

## 自動検証

```sh
npm run typecheck
npm test
npm run build
npm run licenses:verify
```

- 時間範囲の移動・左右端のクランプ・小数duration、Pointer Eventsと数値・プレビューの同期。
- 取り消し後のGIFドロップ、同じGIFの再選択、別ファイルへの変更、URL・結果・画角のリセット。
- 取り消した読み込みが遅れて完了した場合の状態保護。
- 生成開始時の進捗スクロール、表示済みの場合の抑制、動きを減らす設定への対応。
- 実際のWASM coreによる動画・GIF変換と、出力時間が選択上限以内であること。
- ライセンス・ソース・coreのハッシュ、公開リンク、ソースアーカイブと作業ソースの一致。

UIの自動テストにはDOM・メディアイベントの代替環境を使います。
ブラウザの描画、ネイティブのファイル選択、実端末のメモリ制限は別途確認が必要です。
合成素材はテスト内で生成し、配布物へ含めません。

## ユーザーによるnote実環境での確認

| 入力・操作 | 確認できた結果 |
| --- | --- |
| 元の状態ではnoteへ挿入できなかったGIFを、4:3で再変換 | noteへの画像挿入・記事の下書き保存に成功 |
| 同じGIFを自由形で再変換 | noteへの画像挿入・記事の下書き保存に成功 |
| 約6秒・約5 MBの動画で開始・終了を指定してGIF生成 | noteへのアップロード・画像挿入に成功 |

GIF入力では「再変換 → noteへ挿入 → 下書き保存」を確認済みです。
動画入力では「任意範囲指定 → GIF生成 → noteへ挿入」を確認済みです。
動画入力テストの下書き保存、ブラウザ名・OS・動画コーデックについては報告がありません。

## ローカルブラウザでの確認

- PC幅と360px幅で、生成開始時に画面外の進捗エリアへスクロールし、見えている場合は不要な移動がないことを確認。
- 合成GIFの変換完了とエラーがないことを確認。
- PC幅と360px幅でフッターの折り返しを確認。「作者のnote」が指定のページへ別タブで開くことを確認。

360px幅の確認はデスクトップブラウザの表示幅を変更したものです。
Android / iOS実機での操作・保存の確認記録はありません。
上記は確認した素材・環境での結果であり、全形式・全端末での動作保証ではありません。

## 手動で確認する主なケース

以下は追加確認項目であり、自動テストの成功だけでは確認済みにしません。

- [ ] MP4 / MOV / WebM、縦動画・回転情報付き素材のプレビューと出力。
- [ ] 16:9・1:1クロップの最終出力、枠移動・辺や角のリサイズ。
- [ ] 端数のある素材末尾でのスライダー位置、数値入力、長い素材の途中からの選択。
- [ ] 15秒選択と短い選択の出力時間、選択枠の移動と左右端。
- [ ] 透過・差分フレーム・disposalを含むGIF、静止GIF、長いGIFの途中の選択。
- [ ] 容量超過時の自動再圧縮と、保存したファイルの容量・再生・名前。
- [ ] 読み込み・変換・容量調整中の中止と再操作。
- [ ] 取り消し後の別ファイルのドロップ・同一ファイル再選択、複数ファイルの連続処理。
- [ ] Android / iOS実機での入力・タッチ編集・進捗誘導・保存。
- [ ] 大容量・4K素材、壊れたファイルのエラーと再操作。
- [ ] 配信環境でのWorker・WASM読み込み、ライセンスとソース取得リンク。
- [ ] ブラウザのNetworkで、素材を送信するリクエストがないこと。

## 注意する制約

短い動画でも容量・解像度・ビットレートが高いと時間とメモリを使います。
コーデック、特殊な回転・ピクセル比、GIFのフレーム遅延によっては表示を実素材で確認してください。
GIFは半透明を表現できません。長いGIFのシークでは前のフレームから再合成するため待ち時間が生じます。
ページを閉じたり再読み込みしたりすると、未保存の編集内容・結果は失われます。

HTTP配布ファイルの検証方法は [開発ガイド](DEVELOPMENT.md)、
FFmpeg対応ソースの確認範囲は [専用文書](../third_party_source/README.md) を参照してください。
